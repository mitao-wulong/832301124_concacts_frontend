# 学生通讯录管理系统

## 项目简介
这是一个基于前后端分离架构的学生通讯录管理系统

## 功能特性
- ✅ 学生信息的增删改查
- ✅ 联系方式管理
- ✅ 数据分页显示
- ✅ 搜索和筛选功能

## 技术栈
### 前端
HTML5 : 页面结构和表单设计
CSS3 : 样式和响应式设计JavaScript 
(ES6+) : 交互逻辑和API调用Fetch
API : 异步HTTP请求 
DOM操作 : 动态更新UI，

## 技术特点

### 前端特点
1. 纯原生实现 : 不依赖第三方框架，轻量高效
2. 响应式UI : 适配不同屏幕尺寸
3. 异步交互 : 使用async/await实现异步API调用
4. 用户友好 : 包含加载状态、错误提示和确认对话框
5. 客户端搜索 : 提供即时搜索体验
